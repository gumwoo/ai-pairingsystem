# EC2 보안 그룹 설정 가이드

## 필수 포트 개방

### 인바운드 규칙 추가

| 포트 | 프로토콜 | 소스 | 설명 |
|------|----------|------|------|
| 22 | TCP | Your IP | SSH 접속 |
| 5000 | TCP | 0.0.0.0/0 | API 서버 |
| 8000 | TCP | 0.0.0.0/0 | AI 모델 서버 |
| 3307 | TCP | Your IP | MySQL (관리용, 선택사항) |

### AWS 콘솔에서 설정 방법

1. **EC2 대시보드 접속**
   - AWS 콘솔 → EC2 → 인스턴스

2. **보안 그룹 수정**
   - 인스턴스 선택 → 보안 → 보안 그룹 클릭
   - "인바운드 규칙 편집" 클릭

3. **규칙 추가**
   ```
   규칙 추가:
   - 유형: 사용자 지정 TCP
   - 포트 범위: 5000
   - 소스: 0.0.0.0/0
   - 설명: API Server

   규칙 추가:
   - 유형: 사용자 지정 TCP  
   - 포트 범위: 8000
   - 소스: 0.0.0.0/0
   - 설명: AI Model Server
   ```

4. **규칙 저장**

## 테스트 명령어

### 포트 확인
```bash
# EC2에서 실행
sudo netstat -tlnp | grep -E ':(5000|8000|3307)'

# 외부에서 테스트
curl http://15.165.17.165:5000/
curl http://15.165.17.165:8000/health
```

### 방화벽 확인 (Ubuntu)
```bash
# 방화벽 상태 확인
sudo ufw status

# 필요시 포트 개방
sudo ufw allow 5000
sudo ufw allow 8000
```

## 주의사항
⚠️ 보안을 위해 프로덕션 환경에서는 특정 IP만 허용하는 것을 권장
⚠️ MySQL 포트(3307)는 관리 목적으로만 필요시에만 개방
